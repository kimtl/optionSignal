# optionSignal

나스닥이 오르기 직전에 콜이 급등하고, 떨어지기 직전에 풋이 급등하는 현상은 흔합니다. 다만 **ATM 콜 가격과 ATM 풋 가격을 그대로 빼면** 그 신호가 거의 안 보입니다.

선물·지수 옵션은 풋콜 패리티 때문에 ATM에서 `콜 ≈ 풋`입니다. 실제로 뛰는 것은 **돈 근처~OTM 옵션의 수요와 내재변동성**입니다. 이 저장소는 그 차이를 한 숫자로 뽑습니다.

## 어떤 숫자를 보면 되나

핵심 지표는 세 개입니다.

### 1. CPPI — Call-Put Premium Imbalance

근월(기본 DTE ≤ 7), spot ±8% 스트라이크만 남긴 뒤

```
콜 프리미엄 = Σ (중간가 × 거래량)
풋 프리미엄 = Σ (중간가 × 거래량)
CPPI = (콜 − 풋) / (콜 + 풋)
```

- `+1`에 가까움: 콜 시세·거래가 압도 (상승 베팅 자금)
- `−1`에 가까움: 풋 시세·거래가 압도 (하락 헤지/베팅 자금)
- `0`: 균형

거래량으로 가중하는 이유: 호가만 보면 거래 없는 먼 OTM 가격에 속고, 실제로 돈이 들어간 쪽을 못 봅니다.

### 2. 리스크 리버설 — 25Δ 콜 IV − 25Δ 풋 IV

기관이 같은 현상을 IV로 보는 방식입니다. 양수면 콜이 풋보다 비싸고, 음수면 풋이 더 비쌉니다. 나스닥은 원래 풋 스큐가 있어서 **평소에도 약간 음수**인 경우가 많습니다. 중요한 것은 레벨보다 **갑자기 콜 쪽으로 붙거나, 풋 쪽으로 더 벌어지는 변화**입니다.

### 3. 세션 급등 갭 — 거래량 가중 등락률 콜 − 풋

지금 장에서 어느 쪽이 더 세게 뛰고 있는지를 보여 줍니다. 스냅샷을 `data/optionsignal.db`에 쌓으면 같은 숫자를 시계열로도 볼 수 있습니다.

## 왜 QQQ / NDX인가

원하시는 것은 **나스닥 선물옵션(CME NQ)** 기준입니다. 다만 NQ 옵션 호가는 CME 유료 시세라 공짜로 안정적으로 가져오기 어렵습니다.

같은 기초자산(Nasdaq-100)을 추종하는 **QQQ 옵션**과 **NDX 옵션**이 유동성이 가장 좋고, 0DTE까지 있어서 “임박한 급등”을 보기에 더 적합합니다. 선물은 `NQ=F` 가격을 옆에 같이 띄웁니다.

나중에 Databento / CME delayed / 브로커 API 키가 있으면 fetch 레이어만 NQ 옵션으로 바꾸면 됩니다. 지표 공식은 동일합니다.

## 실행

```bash
python -m pip install -e ".[dev]"
python -m optionsignal snapshot
python -m optionsignal snapshot --symbol ^NDX --json
python -m optionsignal dashboard --host 127.0.0.1 --port 8000
```

대시보드는 http://127.0.0.1:8000 입니다.

테스트:

```bash
python -m pytest -q
```

## 읽는 법

| CPPI | 해석 |
| --- | --- |
| ≥ +0.25 | 콜 프리미엄 우세, 상승 베팅이 가격을 밀어 올림 |
| −0.08 ~ +0.08 | 한쪽 급등이라고 보기 어려움 |
| ≤ −0.25 | 풋 프리미엄 우세, 하락 방어/베팅이 가격을 밀어 올림 |

이 수치는 **포지션 추천이 아닙니다.** 옵션 수요가 어디에 몰렸는지의 스냅샷입니다. 헤지 수요, 딜러 감마, 만기일 흐름이 같은 숫자를 만들 수 있습니다.
